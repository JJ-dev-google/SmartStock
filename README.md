# SmartStock - Serverless Inventory Management

A full-stack JavaScript inventory and order management project.

## AWS services
- Amazon S3
- AWS Lambda
- Amazon API Gateway
- AWS CloudFormation
- Amazon CloudWatch
- Amazon CloudFront

## Git branches
- echo: Development
- staging: Staging
- main: Production

## Run locally
Open frontend/index.html in your browser.

## Deployment
Configure AWS credentials and GitHub Actions secrets before deployment.
See infrastructure/template.yaml.
